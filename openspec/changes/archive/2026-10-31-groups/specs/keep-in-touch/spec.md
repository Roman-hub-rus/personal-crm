# Spec Delta

## MODIFIED Requirements

### Requirement: Блок «Пора связаться» на главной
Система SHALL показывать на главной странице над списком контактов блок «Пора связаться» со всеми просроченными контактами и их количеством рядом с заголовком. Блок не показывается, если просроченных контактов нет или в поиске по имени введён запрос. Общий список контактов под блоком не меняется: просроченные контакты есть и в нём. Если на главной выбрана группа, в блоке и в счётчике — только просроченные контакты из неё.

#### Scenario: Есть просроченные контакты
- **WHEN** пользователь открывает главную страницу, и просроченных контактов три
- **THEN** над списком контактов виден блок «Пора связаться» с тремя контактами и числом 3 рядом с заголовком, а в общем списке эти контакты тоже есть

#### Scenario: Просроченных нет
- **WHEN** пользователь открывает главную страницу, и просроченных контактов нет
- **THEN** блока «Пора связаться» на странице нет

#### Scenario: Идёт поиск
- **WHEN** пользователь вводит запрос в поиск по имени
- **THEN** блок «Пора связаться» скрыт, а когда запрос очищен — снова виден

#### Scenario: Контакт удалён
- **WHEN** пользователь удаляет контакт, который был в блоке «Пора связаться»
- **THEN** контакта нет в блоке

#### Scenario: Выбрана группа
- **WHEN** просрочены три контакта, из них два в группе «Теннис», и пользователь выбирает на главной группу «Теннис»
- **THEN** в блоке «Пора связаться» только эти два контакта и число 2 рядом с заголовком

#### Scenario: В группе нет просроченных
- **WHEN** просроченные контакты есть, но ни один не входит в группу «Семья», и пользователь выбирает группу «Семья»
- **THEN** блока «Пора связаться» на странице нет

#### Scenario: Поиск в группе
- **WHEN** выбрана группа «Теннис», в которой есть просроченные контакты, и пользователь вводит запрос в поиск
- **THEN** блок «Пора связаться» скрыт, а когда запрос очищен — снова виден с просроченными из группы «Теннис»
