# Proposal

## Why

Контактов уже сотни, и они лежат одним длинным списком. Чтобы найти «всех из тенниса» или «всю семью», приходится помнить имена. Группы раскладывают людей по кругам общения, которые придумывает сам пользователь, и позволяют смотреть на один круг за раз.

## What Changes

- Появляются группы: семья, друзья, знакомые, теннис, аналитики — любые, какие придумает пользователь. Контакт может входить сразу в несколько групп или ни в одну.
- В карточке контакта и в форме нового контакта появляется поле «Группы»: все группы показаны кнопками-метками, нажатие включает или выключает группу. Кнопка «Новая группа» позволяет вписать название — группа появится сразу отмеченной. Изменения сохраняются кнопкой «Сохранить» (или «Добавить контакт») вместе с остальными полями; новая группа создаётся только при сохранении.
- Новая страница «Группы» (ссылка в шапке сайта): все группы по алфавиту со счётчиком людей, создание, переименование и удаление. При удалении группы люди остаются, они просто выходят из неё. Перед удалением — подтверждение.
- На главной под поиском — ряд кнопок «Все · Аналитики · Друзья · …». Выбрал группу — в списке только её люди, поиск по имени ищет внутри неё, а блок «Пора связаться» показывает только просроченных из этой группы. Выбирается одна группа за раз. Если групп нет, ряда нет.
- В строке общего списка видны названия групп контакта мелкими метками.
- Из карточки, открытой при выбранной группе, ссылка назад возвращает к этой группе.
- На сервере после выкатки групп нет — пользователь заводит свои. В тестовых данных (`pnpm db:seed`) группы есть, чтобы локально сразу было что посмотреть.

## Capabilities

### New Capabilities

- `contact-groups`: группы контактов — создание, переименование и удаление, состав групп в карточке контакта, фильтр по группе и метки групп в списке на главной.

### Modified Capabilities

- `keep-in-touch`: блок «Пора связаться» при выбранной группе показывает только просроченные контакты из неё и их количество.

## Допущения

Решено без отдельного вопроса — поправьте, если не так:

- Название группы — от 1 до 50 символов. Две группы с одинаковым названием без учёта регистра завести нельзя: «теннис» и «Теннис» — одна группа.
- Если в карточке вписать название уже существующей группы, отмечается она, а не создаётся вторая.
- На странице «Группы» нажатие на название открывает главную с этой группой.
- В строке списка — до трёх меток по алфавиту, остальные свёрнуты в «+N».
- Если в адресе указана группа, которой уже нет, главная показывает всех.
- Не входят: цвета и значки групп, выбор нескольких групп сразу, метки групп в блоке «Пора связаться», автоматическая отметка группы при добавлении контакта из отфильтрованного списка, массовое добавление в группу.

## Impact

- База данных: две новые таблицы — группы и связь «контакт — группа». Миграция только добавляет таблицы, существующие данные не меняются. При удалении контакта его участие в группах удаляется вместе с ним.
- Код: схема `src/db/schema.ts`, проверка формы `src/lib/contact-input.ts`, серверные действия `src/app/contacts/actions.ts` и новые действия для групп, выборки `src/lib/contacts.ts` и новый `src/lib/groups.ts`, форма `src/components/contact-form.tsx`, карточка и новый контакт `src/app/contacts/`, главная `src/app/page.tsx`, список `src/components/contact-list.tsx`, поиск `src/components/contact-search.tsx`, шапка `src/components/site-header.tsx`, новая страница `src/app/groups/`, тестовые данные `src/db/fake-contacts.ts`.
- Интерфейс: только уже подключённые компоненты shadcn/ui (`Badge`, `Button`, `Input`, `AlertDialog`), новых зависимостей для интерфейса нет.
- Тесты: в проекте появляется Vitest (есть в стеке CLAUDE.md, но ещё не установлен) — пакеты разработки `vitest` и обязательный для него `vite`, команда `pnpm test`. Тесты идут на настоящей базе в Docker, в отдельной тестовой базе рядом с основной. Каждый сценарий из спецификаций — свой тест. e2e-тесты для групп и CI — отдельным изменением позже, по решению владельца; существующие e2e должны остаться зелёными.
- Выкатка: обычная — миграция применяется отдельным шагом до старта нового образа.
