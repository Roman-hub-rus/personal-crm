# Spec Delta

## MODIFIED Requirements

### Requirement: Название группы
Система SHALL обрезать пробелы по краям названия группы и принимать названия длиной от 1 до 50 символов. У одного пользователя не может быть двух групп с одинаковым названием без учёта регистра: «теннис» и «Теннис» — одна группа. У разных пользователей названия групп могут совпадать. Ошибки: «Введите название группы», «Название слишком длинное — не больше 50 символов», «Группа «<название>» уже есть».

#### Scenario: Пустое название
- **WHEN** пользователь создаёт группу с названием из одних пробелов
- **THEN** группа не создаётся, и видно «Введите название группы»

#### Scenario: Слишком длинное название
- **WHEN** пользователь создаёт группу с названием из 51 символа
- **THEN** группа не создаётся, и видно «Название слишком длинное — не больше 50 символов»

#### Scenario: Пробелы по краям
- **WHEN** пользователь создаёт группу с названием «  Теннис  »
- **THEN** появляется группа «Теннис» без пробелов по краям

#### Scenario: Такая группа уже есть
- **WHEN** группа «Теннис» уже есть, и пользователь на странице «Группы» создаёт группу «теннис»
- **THEN** вторая группа не создаётся, и видно «Группа «Теннис» уже есть»

#### Scenario: Такая же группа у другого пользователя
- **WHEN** у пользователя A есть группа «Друзья», и пользователь B создаёт группу «Друзья»
- **THEN** у B появляется своя группа «Друзья», а у A по-прежнему одна своя «Друзья» с прежними людьми

#### Scenario: Переименовал в название группы другого пользователя
- **WHEN** у пользователя A есть группа «Теннис», и пользователь B переименовывает свою группу в «Теннис»
- **THEN** у B видно «Группа переименована», и обе группы «Теннис» существуют каждая у своего владельца

#### Scenario: Вписал в карточке название группы другого пользователя
- **WHEN** у пользователя A есть группа «Теннис», и пользователь B вписывает в карточке своего контакта новую группу «Теннис» и сохраняет
- **THEN** у B создаётся своя группа «Теннис» с этим контактом, а в группе A никто не добавился
